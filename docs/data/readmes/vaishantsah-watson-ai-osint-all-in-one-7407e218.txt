What is Watson

Watson is a free OSINT search tool (open-source intelligence) for Windows. It
collects the trail a person leaves in public places — social networks, forums,
games, developer sites — and turns it into a readable answer.

Type a nickname, email, phone number or website and Watson checks
3,100+ public sources for profiles and mentions. It's a digital footprint
check, a username lookup and a social media search in one window — no terminal,
no Python, no API keys.

Use it to vet sellers before you pay, check a job offer, look at a new
acquaintance, or see what the internet knows about you.

You're about to do business with someone. Do you actually know who they are?

The answer is already out there, scattered across 3,100+ public sites. Finding it by hand takes a weekend, a dozen browser tabs and the patience of a detective.

Install in 2 minutes

No setup wizard, no account, no admin rights. Download one file and open it.

1. Download

Two ways, same file:

- From the website: open watsonfind.icu and click Download free.
- From GitHub: open Releases and download Watson-1.4.0-portable.exe.

Both serve the same build — pick whichever you prefer.

2. Open it

Double-click the file you downloaded. If Windows shows a blue warning, click More info, then Run anyway. You only do this once.

Why does Windows warn me?

Windows shows this screen for any new app that hasn't paid for a code-signing certificate yet. It does not mean the file is harmful. Once Watson is signed, the warning goes away.

3. Search

Type what you know and press Enter.

4. Read the answer

That's it. There is nothing else to learn.

No Windows? The desktop app is Windows-only for now; a Mac version may come later.

Questions

How much does it cost?

Nothing. Watson is free, with every feature included. There is no paid version.

Do I need an account?

No. There is no sign-up and no login. Your search history is saved only on your own computer.

Is this legal?

Watson only looks at information that is already public: things anyone could find with a browser and enough time. It doesn't hack, log in as anyone or buy leaked data. How you use what you find is up to you, so follow the law where you live.

Does it work on Mac?

There is no Mac download yet.

Do I need to install anything else?

No. The .exe has everything inside. Delete the file and it's gone.

The download link says 404

This repository is private. Ask the owner to add your GitHub account as a collaborator, then sign in and open the link again.

What do "Same person" and "Name match" mean?

Same person (green): the profiles link to each other or share photos and details, so they almost certainly belong to one person.

Name match (grey): only the nickname is the same. It could be someone else.

Use it responsibly

Watson is built for checking who you're dealing with: vendors, partners, sellers, job offers and your own online footprint. Don't use it to stalk, harass or threaten anyone.

For developers

Run from source, build the .exe, project layout

Requirements

Node.js 22 or newer.

Run the site

npm install
npm run dev

Then open http://localhost:5173.

Run as a desktop app

npm run app

Website (watsonfind.icu)

The site is a static landing page; the app itself lives in the desktop build:

| URL | What's there |
| --- | --- |
| watsonfind.icu/ | Landing page: src/pages/Landing.tsx |
| dist/app.html | The app, loaded by the Electron window |

Build it with npm run build and upload the dist/ folder to any static host. public/_redirects handles SPA fallback on Netlify and Cloudflare Pages, and vercel.json on Vercel. Point the watsonfind.icu DNS records at your host. The host must also serve the .exe at /api/download (see DOWNLOAD_URL in src/pages/Landing.tsx).

The download buttons use DOWNLOAD_URL in src/pages/Landing.tsx; on this server nginx serves the .exe from /api/download.

Build the Windows .exe

npm run dist:win

The file lands in release/Watson-1.4.0-portable.exe. Building on Linux works without Wine, but then the .exe keeps the default Electron file icon. Build on Windows to embed the Watson icon.

Stack

Vite, React 19, TypeScript, Tailwind CSS 4, Electron. Icons: Phosphor and Simple Icons.
