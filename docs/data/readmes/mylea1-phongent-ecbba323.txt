phongent 是什么

phongent 是一个多设备 agent 协同控制项目。你可以用 iPhone 或安卓手机连接多台安卓设备，向全部设备、某一组或指定设备下发任务，并集中查看执行结果；通过主控设备查看被控制设备接收到的所有弹窗信息，并在主控设备中直接回复。

安卓既可以管理其他设备，也可以直接操作本机；iOS 作为主控连接安卓执行端。

| 设备角色 | iOS | Android |
| --- | --- | --- |
| 作为主控，连接和管理其他安卓设备 | 支持 | 支持 |
| 分配任务、查看结果与消息 | 支持 | 支持 |
| 查看安卓实时小窗、接管操作 | 支持 | 支持 |
| 执行本机 App 操作任务 | — | 支持 |

核心功能

- 多设备任务分配：长按对应设备，直接描述对应设备的任务，或是让主控的任务代理自行下发任务。
- 按组协作：批量分组、折叠组内头像、选中整组下发任务；支持不同组不同任务，以及组内单独指定任务。
- 内容创作与分发：主控模型可生成多份文案和文字图卡，将各自内容与任务交给对应设备；支持附带图片。
- 实时小窗：查看安卓虚拟屏画面，通过点击、滑动和输入接管操作；小窗默认开启，可在设置中关闭。
- 消息集中查看：按设备、应用、消息来源组织通知，查看详情并通过目标设备的 agent 回复。
- 集中配置：管理记忆、技能、定时任务、操作路线等，按功能选择单台或批量操作。
- 连接与管理：局域网发现、授权连接、一键连接、断线重连、设备重命名和已连接设备网格。

怎么下发任务

例如：

A 打开小红书主页并截图，B 打开浏览器查看今天的天气。

内容组分别生成一份产品介绍草稿，检查组查看各设备的任务状态。
内容组里的 A 改为整理已有素材，其余设备继续生成草稿。

为内容组的每台设备生成不同的标题、正文和文字图卡，
分别下发给对应设备，保存为草稿，暂不发布。

快速开始

1. 安装本项目的构建。 安卓安装 对应 APK；iOS 当前通过 Xcode 构建并签名安装。请勿用上游项目的 APK 替代本项目执行端，它可能缺少群控接口。
2. 配置安卓执行端。 在应用内完成模型配置和手机操作设置，按功能授予无障碍、通知读取等所需权限。手机操作的底层设置可参考设置指南，其中部分名称仍沿用上游。
3. 连接设备。 主控与执行端接入同一局域网，保持安卓端服务运行；主控在“设备”页选择设备或点击“一键连接”，首次连接在安卓端允许。已授权设备支持重连。
4. 配置主控模型。 在主控设置中配置任务下发模型；账号登录在对应设备上完成。
5. 开始协作。 在 agent 页选择全部、设备组或单台设备，输入任务，按设备查看进度和结果。

设备与分组

- 下方网格只显示已连接设备，卡片标注名称与所属组。
- 点击“分组”，勾选设备，选择已有组或新建组，再点击“移动 N 台”。
- 每台设备属于一个组；移动后离开原组。未分组的设备归入“默认组”。
- 长按设备头像或卡片，可重命名或移动分组。重命名会同步到对应安卓 App 内的设备名称，需要执行端支持该接口。
- agent 页左侧按组显示头像，支持折叠。分组保存在当前主控端，不会自动同步到其他主控。

四个入口

| 入口 | 用途 |
| --- | --- |
| 设备 | 发现、连接、重命名、分组 |
| agent | 分配任务、查看执行结果和实时小窗 |
| 消息 | 按设备、应用、来源查看通知 |
| 设置 | 配置主控、执行端及同步选项 |

Android：JDK 17、Android SDK（当前 compileSdk 36）；最低安装版本 Android 11，具体手机操作能力另受系统版本与权限限制。

./gradlew :app:assembleDebug

产物位于 app/build/outputs/apk/debug/；安装前确认构建产物已使用自己的开发签名签署。

iOS：macOS、支持项目所用 SDK 的 Xcode，最低部署版本 iOS 17。打开 ios/MikaRemote.xcodeproj，选择 MikaRemote scheme，在签名设置中选择自己的开发团队后构建。

模型密钥、账号凭证和本机签名材料不应写入源码。
