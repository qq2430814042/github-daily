Modules and Settings

Aim Assistance Module
Controls crosshair behavior so the aim point drifts toward visible opponents during Rivals matches.
- Targeting Priority lets the user choose whether the assist favors the nearest threat or the most central target on screen.
- Smoothing Strength adjusts how quickly the crosshair settles onto a target, ranging from a quick snap to a gentle pull.
- Activation Toggle enables or disables the assist independently of all other modules so the user can play with manual aim only.
- The module works with Hitbox and Aim Point Selection to determine where on the opponent the crosshair converges.

Trigger Automation Module
Releases shots automatically when the crosshair overlaps a valid target, with user-defined timing and range conditions.
- Reaction Delay sets how long the crosshair must remain on target before a shot fires, preventing instant releases.
- Per-Weapon Toggles let the user enable automation for some weapon types while leaving others fully manual.
- Minimum Activation Distance limits automation to targets within a chosen range so distant engagements stay manual.
- The module respects the aim point chosen in the Aim Assistance module, so automated shots follow the same targeting region.

Movement Modifiers Module
Exposes movement parameters as individual controls so the user can tune character motion during a match.
- Walk Speed Multiplier adjusts how fast the character moves within script-defined bounds.
- Jump Height Control raises or lowers jump arcs as a separate slider, independent of speed.
- Each modifier has its own toggle, letting the user combine settings or keep some disabled.
- Changes take effect alongside the active Configuration Profile, so movement behavior switches together with combat settings.

PLAYER INFORMATION DISPLAY and Target Highlighting Module
Renders visual overlays that outline opponents and display positional information during matches.
- Outline Color and Opacity settings keep overlays readable against different map backgrounds.
- Maximum Render Range caps how far away highlights appear, reducing clutter at long distances.
- Distance Indicators show how far each highlighted opponent is from the user.
- Overlays update as players move, and the module can be toggled independently of aim and trigger features.

Hitbox and Aim Point Selection Module
Determines which body region the aiming systems prioritize when converging on a target.
- Preset Aim Points let the user switch between regions such as head or torso.
- Hitbox Expansion widens the effective target area within configurable limits for more forgiving aim convergence.
- The selected aim point feeds directly into both Aim Assistance and Trigger Automation, keeping all aiming behavior consistent.
- Switching presets takes effect immediately without reloading the script.

Recoil and Spread Adjustment Module
Compensates for weapon recoil and bullet spread during sustained fire.
- Vertical Compensation and Horizontal Compensation are adjusted separately to match different recoil patterns.
- The module layers on top of Trigger Automation, so automated shots benefit from the same compensation settings.
- Compensation levels can be dialed back or disabled entirely for users who only want partial stabilization.
- Results are visible as tighter shot groupings that reflect the chosen settings.

Additional Settings
