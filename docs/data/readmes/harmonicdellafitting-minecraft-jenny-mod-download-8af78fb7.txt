📦 Installation Guide

We provide separate files for Java Edition (Forge) and Bedrock Edition (MCPE).

🟢 For Java Edition (Forge 1.18 - 1.21.11)
1. Go to the Releases page.
2. Click the Download button in the latest release description.
3. Extract the ZIP file and find the .jar file for your version.
4. Place the .jar file into your %appdata%\.minecraft\mods folder.
5. Launch the game using the Forge profile.

🔵 For Bedrock Edition (MCPE/Android)
1. Download the .mcaddon file from the Releases page.
2. Open the file with Minecraft to install it automatically.
3. Activate the behavior pack and resource pack in your world settings.
