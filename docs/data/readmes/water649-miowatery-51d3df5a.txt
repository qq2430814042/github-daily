Mio水汪汪（小手机）

一个跑在浏览器里的全屏 AI 聊天手机模拟器。单个 HTML 文件，没有构建步骤，不需要后端就能聊天。

接入任何 OpenAI 兼容的 API，和你设定的角色聊天、写朋友圈、查手机、一起听歌、打电话、线下剧情等。可以添加到 iOS / Android 主屏幕，当 PWA 使用。

非官方项目。界面灵感来自 iOS、KakaoTalk、X、Apple Music、Apple Books、YouTube 等产品，与这些公司没有任何关系。

快速开始

1. 把仓库里的文件放到任意静态托管上（GitHub Pages、Cloudflare Pages、自己的服务器都行）。
2. 用手机或电脑浏览器打开。
3. 进「设置」，填写你自己的 API 地址、Key 和模型。
4. 新建角色，开始聊天。

数据（聊天记录、角色、设置、API Key）都保存在你自己浏览器的本地存储里，不会上传到作者的服务器。清除浏览器数据会一并清掉，记得先用应用里的导出功能备份。

分享你的桌面

「桌面美化」应用的「更多」页里有「美化包」：

- 导出当前桌面美化：把壁纸、软件图标、小组件、自定义组件和摆放位置打包成一个 .json 文件，可以保存为文件或复制代码。
- 导入美化包：选择别人发你的文件，或粘贴代码，一键换上同样的桌面。导入会替换你当前的桌面美化，建议先导出备份。

美化包里的自定义组件带有代码，在沙盒里运行，没有聊天权限，也不能联网。只导入你信任的来源。

| 功能 | 默认 | 说明 |
| --- | --- | --- |

自己部署仓库服务

server/repo/server.py 是仓库的服务端，只用 Python 标准库（3.8+），不用装任何包。

cd server/repo
ADMIN_KEY=你的管理密钥 TRUST_PROXY=1 python3 server.py

然后在应用的仓库设置里把服务器地址改成你的。管理页面在 /admin，不设置 ADMIN_KEY 则管理功能关闭。

| 环境变量 | 默认 | 说明 |
| --- | --- | --- |
| PORT | 8787 | 监听端口 |
| DATA_DIR | ./data | 作品存放目录 |
| ADMIN_KEY | 空 | 管理密钥，不设置则关闭管理功能 |
| IP_SALT | 内置默认值 | 给 IP 做哈希的盐，部署时请改成你自己的随机字符串 |
| TRUST_PROXY | 0 | 放在 Caddy、nginx 等反向代理后面时设为 1 |
| REPORT_HIDE | 3 | 几个不同的人举报后自动隐藏 |
| MAX_WORK_BYTES | 4 MB | 单个作品附件总大小 |
| UP_PER_HOUR | 10 | 每个 IP 每小时最多上传几个 |

建议前面套一层反向代理并开启 HTTPS，PWA 和浏览器访问都要求 HTTPS。用 Caddy 的话，Caddyfile 这样写就行，证书会自动申请：

repo.example.com {
    reverse_proxy 127.0.0.1:8787
}

跨域（CORS）由 server.py 自己处理，代理不用再配。

光遇

光遇陪玩依赖运行在你自己电脑上的 sky-pc-mcp-companion，再通过隧道或反向代理暴露给小手机。在「MCP」应用的「光遇」页填写服务地址和访问令牌。令牌等同于控制你电脑的权限，不要给别人。
