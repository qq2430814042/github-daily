short-lived posts: clean setup, configuration hygiene, display and hotkey

Quick start

1. Read docs/installation.md before unpacking anything.
2. Verify the archive and use the password shown above.
3. Keep the package outside the Steam library and back up your configuration.
4. Check docs/safety.md before using third-party software.
5. Use docs/troubleshooting.md when the overlay,
   display mode, or configuration does not behave as expected.

This repository contains no executable and no loader. If a mirror asks you to
disable antivirus, run an unsigned binary as administrator, or send account
credentials, stop and verify the source.

Configuration principles

- Keep one profile per display setup and one backup before every update.
- Prefer windowed borderless when an overlay is involved.
- Record the exact game build, GPU driver, and overlay version in bug reports.
- Never store Steam credentials, session tokens, or recovery codes in a config.
- Treat public configs as untrusted input; inspect them before use.

More detail: docs/configuration.md.

Safety and limitations

Third-party software can violate Valve's terms and lead to a VAC or game ban.
This hub does not provide anti-cheat bypasses, hidden offsets, or a guarantee
that any external package is safe or available. Use a separate account only if
you understand and accept the risk. No warranty is provided.

Read the full note: docs/safety.md.
