Guanmo Studio

选一个喜欢的视频模板，放进你的内容，创作一支属于自己的短片。

第一个模板是「卡片转盘」：一叠卡片展开、旋转，再聚焦一个主角，十五秒里把你的作品、产品或故事有序地讲出来。从选样式、预览到导出 1080p / 60fps 成片，全部在你的电脑上完成。免费开源，不需要登录，也不调用付费模型；也可以把它交给 AI，让它替你完成。

三步做出这支样片

需要 Node.js 22+、Python 3.10+ 和 FFmpeg。还没安装的话，先看 各系统安装方法。

1. 获取代码：

git clone https://github.com/guanmo-ai/guanmo-studio.git
cd guanmo-studio

2. 安装依赖（只需一次，会自动下载匹配的浏览器）：

npm ci
npm run setup
npm run doctor -- --render --probe

诊断全部显示「通过」就可以开始了。

3. 导出样片：

npm run update -- studio-demo --final

成片保存在 renders/studio-demo.mp4，和上面的样片一致。想先快速看一遍，把 --final 换成 --draft（960×540 草稿）；再加 --edit-pack 可额外导出六段画面、配乐和音效分轨，放在 renders/studio-demo-edit/。

创作你自己的视频

复制带样式和配乐的起点配置，起一个新的项目名：

cp -r examples/styled-starter examples/my-project

Windows PowerShell：Copy-Item -Recurse examples/styled-starter examples/my-project

打开 examples/my-project/config.json，主要改这几处：

| 字段 | 作用 |
| --- | --- |
| brand.wordmark / brand.tagline | 项目名称和一句话介绍 |
| cards | 7—31 张卡片，每张写 title（标题）和 sub（副标题）；有图片时用 front: "image" 和 image |
| featured / hero | 依次展示的 6 张精选卡，以及最后展开的主角卡 |
| background.preset | 内置背景的 ID |

然后依次检查、出片：

npm run update -- my-project            # 快速关键帧，先看画面
npm run update -- my-project --draft    # 15 秒连续草稿
npm run update -- my-project --final    # 高清成片

关键帧在 renders/my-project.proof-checks/，成片在 renders/my-project.mp4。全部字段见 配置说明。

让 AI 来做：把 制作提示词 和你的项目地址交给 Claude Code、Codex 等编程助手，它会按 模板说明 选内容、改配置、检查画面并导出。

能做什么

当前有 1 个动画模板：Card Carousel（卡片转盘）。

- 15 秒、1920×1080、60fps；快速草稿为 960×540、30fps
- 7—31 张图片或文字卡片，六张精选牌依次展示，一个主角展开
- 30 组可选色卡，支持先预览再加入、随机均分与保存选择
- 背景、卡片材质、内容、配乐和音效独立配置，音效可按镜头时间点在本地合成
- 本地预览、逐帧导出与六段剪辑素材包

项目处于 0.1 预览阶段。当前只支持这一种横版编排；竖版、其他时长、时间线编辑和多用户服务尚未实现。代码采用 MIT，随包素材的许可见 素材清单。

安装细节

克隆仓库或解压对应版本的源码包，在项目目录打开终端。需要 Node.js 22+、Python 3.10+ 和 FFmpeg（含 ffprobe）。仅浏览网页时不需要 FFmpeg。macOS、Windows PowerShell 和 Linux 使用相同的项目命令；系统依赖安装方法见 跨平台安装与验证。

npm ci
npm run setup
npm run doctor -- --render --probe

setup 创建仓库独立的 Python 环境，安装锁定版本的 Pillow 和匹配的 Chromium，无需手动激活虚拟环境。Linux 首次安装可用 npm run setup -- --with-deps 补齐浏览器系统库。只构建、不渲染可用 --skip-browser。诊断的 --probe 会实际启动浏览器并检查 WebGL2。

也可以使用已安装的 Docker 与 Compose v2，统一在 Linux 容器中制作：

npm run container -- doctor --render --probe
npm run container -- update starter --draft

容器自动构建本地镜像，成片写入宿主机 renders/，examples/ 只读挂载。该入口用于批量导出；网页工作台在本机运行。各平台的实际验证状态见 支持矩阵。

已有镜像且只替换示例内容时，可用 npm run container -- --no-build update starter --draft 复用镜像，不拉取或重建；更新工具代码后去掉 --no-build 重新构建。

从不含外部图片、默认无声的入门配置开始：

npm run update -- starter           # 构建并生成快速关键帧
npm run preview -- build/starter    # 浏览器交互预览
npm run update -- starter --draft   # 完整 15 秒草稿
npm run update -- starter --final   # 高清 MP4

关键帧位于 renders/starter.proof-checks/，草稿为 renders/starter.draft.mp4，高清成片为 renders/starter.mp4。每次修改配置后，先查看关键帧，再查看连续草稿，确认后导出高清。

构建和渲染分别在临时目录或临时 MP4 中完成，成功后才替换旧工程或成片。配置、素材解码、编码或剪辑包失败时保留旧输出；视频、检查报告与剪辑包完成后一起保存。渲染时按 Ctrl+C 会停止浏览器与编码器，并清理本次临时产物；不要把自己的源文件放进生成目录。

浏览与选择样式

npm run studio       # 浏览模板，点开详情看案例
npm run card-studio  # 卡片样式工作台

打开终端输出的本机地址。卡片工作台可用 30 组色卡试配版式、材质和光位。

点色卡只单独预览，点击「加入这款样式」才加入使用列表。多种样式会按卡片数量尽量均分并随机打散，正反面保持同类；切换镜头不重新分配。「保存这套样式」写入本机 .local/card-style-selection.json，不会改写正式示例或自动生成视频。详细流程见 样式工作台。

将保存的工作台方案应用到 Studio Demo：

npm run update -- studio-demo --saved-style
npm run update -- studio-demo --saved-style --draft
npm run update -- studio-demo --saved-style --final

结果写入独立的 studio-demo-selected 工程与输出，不覆盖正式示例。当前保存方案仅适用于此工作台示例；新项目仍从 Starter 配置开始。保存后继续调整会标为未保存修改；「恢复已保存方案」只恢复浏览器状态，不写入文件。

制作细节

上方「创作你自己的视频」用的是一键入口 npm run update。需要分步控制时，可以分别构建和渲染。起点推荐 examples/styled-starter/（带样式卡面、配乐和音效）；想要纯文字、默认无声的版本用 examples/starter/。图片、图标与音轨路径相对于配置文件：

npm run build -- examples/my-project/config.json --out build/my-project
npm run render -- build/my-project --proof-only
npm run render -- build/my-project --draft --out renders/my-project.draft.mp4
npm run render -- build/my-project --out renders/my-project.mp4 --edit-pack

- 背景：background.preset 使用背景目录 ID；自备图片用 background.image，二者择一
- 卡片：cards 设置内容，theme.cardLook 独立选择结构与材质；original 为原版轻薄卡片
- 音频：把自带 BGM 放进项目的 assets/，在配置中填写 audio.music.path（如 assets/my-music.wav）。启用配乐并省略路径时优先读取 .local/card-carousel/default-music.wav。没有本地默认曲时使用随包的原创合成配乐。详见音轨配置。
- 音效：Styled Starter 自带音效。运行 npm run sfx -- --out examples/my-project/assets/sfx.wav 生成 WAV，填入 audio.sfx.path 即可混入成片。支持 自定义镜头时间点。
- 剪辑：--edit-pack 输出六段已合成的无声画面、启用的音轨、时间表与可搬移重建的源配置

剪辑包不是分层合成工程。替换已合成的卡片与文字需要重新渲染，详见 剪辑说明。

各命令支持 --help。常见安装与运行问题见 故障排查。

让 AI 使用

在线体验或本地网页中，打开模板详情可以复制完整制作提示词。复用当前程序卡面时，从 examples/styled-starter/config.json 开始。它保留最新卡背样式，并启用默认配乐和 CC0 音效。有项目原图时用 cards].front: "image" 与 image 显示完整卡面。为不同项目使用不同目录，按提示词先核对仓库能力，再生成关键帧、草稿和高清成片。纯文字基础形式仍可使用 examples/starter/config.json。

内容替换通常只需修改配置与素材。动画节拍位于 templates/card-carousel/assets/engine/choreo.js，段落定义位于 timeline.json；修改时间编排时需同步维护。
