How it works

Under the hood, the release pipeline is a single self-contained Windows x64 package that unpacks the full Vice City and Leonida world locally — no launcher handshakes, no background phone-home checks. It stages the game assets, wires up the Rockstar-adjacent runtime hooks, and drops you straight into single-player.

The flow is deliberately short: the package verifies its own integrity, decompresses the world and mission data, registers the required Windows x64 runtime libraries, and hands off to the game executable. Every step runs locally on your machine — nothing is streamed from a remote node, and no layer sits between you and the game.

Config detection is automatic. The pipeline reads your GPU and driver state, picks a sensible preset for your hardware, and writes a clean profile so the first boot lands in a playable state rather than a menu crawl. You can retune everything afterward from the in-game settings menu; the pipeline never locks you out of your own configuration.

Session state is isolated per user profile, so saves, settings, and world progress stay clean across launches. The package also includes a lightweight integrity pass you can run any time — it re-checks the staged files against the manifest and repairs what drifted, which keeps long-running installs stable.

Think of it as a single-player-only, open-access build for testing and deployment: one package, one pass, no gatekeeping layer. If you're running Windows 10 or 11 on x64 desktop hardware, you're in the supported lane from the first launch to the last mission.

Configuration

Tune it once, forget it. The defaults are already dialed in for smooth frame pacing, but the config panel gives you full control when you want it.

Config file location: drop gta6pc.toml next to the executable — it picks up automatically on launch. No file, no problem: the build runs on baked-in defaults.

What you can adjust:

- Render pipeline — switch between Quality and Performance presets, or set a custom frame cap to match your refresh rate.
- Memory allocation — dial in VRAM headroom for your GPU; useful on 8 GB cards running high-res textures.
- Load priority — boost asset streaming for dense Vice City traffic scenes, or keep it balanced for stable thermals.
- Input profile — map controller and keyboard layouts per-game, stored locally so your bindings survive updates.

Hot-reload: most values apply instantly — hit F5 in-game and the panel refreshes without a restart. Only render pipeline changes need a relaunch.

Sanity checks: the tool validates every edit on load. If a value is out of range, it falls back to the safe default and logs the entry to config.log so you know exactly what got bounced back.

Backups: your previous config is snapshotted to config.bak every save. One bad edit won't brick your setup — restore in seconds.

Defaults are tuned for a mid-to-high rig. Tweak only what you understand, and the build stays rock-solid.
