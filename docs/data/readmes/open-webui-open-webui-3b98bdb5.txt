Open WebUI

Open WebUI is a home for AI: an extensible, easy-to-use, self-hosted platform built to run entirely offline. Connect local models through Ollama or use OpenAI-compatible APIs for local and cloud models.

Installation

Python

With uv installed (macOS/Linux)
DATA_DIR=~/.open-webui uvx --python 3.12 open-webui@latest serve

Or install and run with pip (Python 3.12)
pip install open-webui
open-webui serve

Then open http://localhost:8080.

Docker

docker run -d -p 3000:8080 --add-host=host.docker.internal:host-gateway -v open-webui:/app/backend/data --name open-webui --restart always ghcr.io/open-webui/open-webui:main

Then open http://localhost:3000.

| Image tag | Includes                                                                                 |
| --------- | ---------------------------------------------------------------------------------------- |
| :main   | Standard image with local AI dependencies                                                |
| :slim   | Lightweight image using external services for embeddings, document extraction, and voice |
| :cuda   | Open WebUI with CUDA acceleration                                                        |
| :ollama | Open WebUI bundled with Ollama                                                           |
| :dev    | Latest development build                                                                 |

Add these options to docker run before the image name as needed:

| Option                                               | Purpose                                                                                  |
| ---------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| -e OLLAMA_BASE_URL=http://your-ollama-server:11434 | Connect to Ollama on another server                                                      |
| -e OPENAI_API_KEY=your_secret_key                  | Set your OpenAI API key                                                                  |
| -e HF_HUB_OFFLINE=1                                | Disable Hugging Face model downloads for offline use                                     |
| --gpus all                                         | Enable Nvidia GPU access for :cuda or :ollama; requires the Nvidia Container Toolkit |

See the Docker installation guide for setup instructions and configuration options.

Ecosystem

- Open Terminal / Terminals (Enterprise): The action layer that turns Open WebUI into a full agent harness, with enterprise orchestration for per-user workspaces.
- Knowledge Base Sync (oikb): Mirror folders, repos, buckets, and wikis into Open WebUI Knowledge Bases with incremental sync.
- Open WebUI Computer: Your computer in any browser: files, editor, terminal, git, and optional AI agents, running on your real machine.
