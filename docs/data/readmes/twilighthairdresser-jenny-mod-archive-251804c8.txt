🧐 What is this Archive?

The Jenny Mod (also known as Fapcraft) is one of the most famous and sought-after mods in Minecraft history. It introduces fully interactive NPCs, a complex gift system, and a virtual girlfriend experience that goes far beyond standard villagers.

However, the original mod was abandoned on version 1.12.2. This repository serves as a Community Archive—a stable port that brings the full Jenny experience to modern versions of Minecraft (Forge 1.18 - 1.21.11) and Bedrock Edition (MCPE).

📦 Installation Guide

We provide separate files for Java Edition (Forge) and Bedrock Edition (MCPE).

🟢 For Java Edition (Forge 1.18 - 1.21.11)
1. Go to the Releases page.
2. Click the Download button in the latest release description.
3. Extract the ZIP file and find the .jar file for your version.
4. Place the .jar file into your %appdata%\.minecraft\mods folder.
5. Launch the game using the Forge profile.

🔵 For Bedrock Edition (MCPE)
1. Download the .mcaddon file from the Releases page.
2. Open the file with Minecraft to install it automatically.
3. Activate the behavior pack and resource pack in your world settings.

❓ Frequently Asked Questions

Is this the official Jenny Mod?
No, this is an unofficial community archive. We are fans of the original concept and wanted to make it playable on modern versions of Minecraft.

Why does my antivirus block the file?
It's a standard false positive. Because the mod modifies game files and uses custom AI hooks, Windows Defender may flag it. Add the file to your exclusions if needed. This is safe.

Will I get banned on servers?
This is a client-side mod. As long as you don't use it on public servers that specifically ban it, you are safe. Always check server rules.
