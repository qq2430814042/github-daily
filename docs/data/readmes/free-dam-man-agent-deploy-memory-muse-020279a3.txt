部署代理记忆 · Muse 版

全球破甲 · 全球破墙 — 把「找免费平台 → 部署加密节点 → 出小火箭订阅二维码」写成可粘贴进 Muse 的长期记忆。

这是什么

一份纯方法论记忆文件：没有任何人的账号、节点、IP、域名、邮箱、密码、UUID 或订阅链接。收到方用自己的账号、自己生成的参数，从零建自己的节点。

配套还有：

- Grok Bot 版
- Antigravity 版

怎么用

1. 打开 DEPLOY_MEMORY.md，整份发给对方。
2. 让对方把全文粘贴给自己的 Muse，并说一句：

把这份存进你的长期记忆，以后部署代理节点都按它执行。

3. 以后派活用这一句：

用临时邮箱免卡注册，部署 xray（VLESS+WS+TLS），拨测通过后直接出小火箭订阅二维码。

交付写死（不许降标准）

1. 订阅链接（挂自己的域名，不暴露服务器真实地址）
2. 二维码
3. 实测出口国家/城市
4. 限额与脾气说明

验收：中立机器真连，generate_204 = 204，出口归属地对得上；最终以主人手机实测为准。
