Windows Image Viewer & Photo Manager is a fast, lightweight, free, and open-source desktop image viewer for Windows. Browse photos, navigate folders, edit images, organize files, and optionally play videos through a clean graphical interface without needing command-line knowledge.

⬇️ Installation

Download the Windows application

1. Open the repository's Releases page.
2. Download the latest release archive Windows Image Viewer & Photo Manager 4.1.5.zip.
3. Extract the archive into a folder of your choice.
4. Keep Windows Image Viewer & Photo Manager 4.1.5.exe and libvlc.dll together in that folder.
5. Double-click Windows Image Viewer & Photo Manager 4.1.5.exe to launch the application.

✨ Features

- ⚡ Fast Image Viewing — Open images quickly and browse large collections with responsive navigation and minimal interface distractions.
- 🔍 High Quality Image Scaling — Enjoy sharp image rendering with configurable scaling and zoom controls for different screen sizes.
- ✂️ Built-In Photo Editing — Crop, rotate, and resize pictures directly inside the Windows image viewer.
- 🗂️ Folder and Thumbnail Browser — Navigate image directories using convenient thumbnails and a dedicated folder browsing mode.
- 📁 Quick File Organization — Copy or move photos to frequently used destination folders with configurable keyboard shortcuts.
- 🎬 Optional Video Playback — Enable multimedia playback through the optional libmpv integration, including supported formats such as WebM.
- ⌨️ Customizable Keyboard Shortcuts — Configure controls, personalize the interface, and access common image management actions without navigating menus.
- 🖥️ Fullscreen and Slideshow — View images without distractions, launch slideshows, and explore collections in shuffle mode.
- 📷 Image Information — Inspect available image metadata and EXIF information through the built-in information panel.
- 🛠️ Custom Script Integration — Configure external commands and scripts to extend image workflows and automate repetitive tasks.

🚀 Usage

Getting started is straightforward:

1. Open an image — Select an image file or open a directory containing your photos.
2. Browse your collection — Use the arrow keys or mouse wheel to move between images.
3. Adjust the view — Zoom in, zoom out, or switch between window, width, and original-size viewing modes.
4. Organize pictures — Use the quick copy and move controls to transfer images between destination folders.
5. Edit images — Access the editing commands to crop, rotate, or resize your current picture.
6. Customize settings — Adjust keyboard shortcuts, themes, interface preferences, and optional integrations.
