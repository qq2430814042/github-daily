❓ Frequently Asked Questions

Q: Are these cheats safe to use?
A: They read memory and draw an overlay, so nothing in the Steam library is modified. Detection risk is never zero in an online game, and the risk grows with every patch the loader hasn't seen.

Q: How do I uninstall them?
A: Close the overlay, delete the folder, remove %APPDATA%\RRX if you want the config gone too. No system files are touched.

Q: What is the difference between this menu and the dupe tool?
A: The dupe tool is one module inside this menu. It automates a duplication sequence the server still has to accept — if Kefir patches the sequence, the tool keeps replaying a dead one until the loader updates.
