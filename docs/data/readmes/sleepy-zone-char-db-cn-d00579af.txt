  line: "../二次元换装库/originals/line/"

提示词是怎么拼的

按作者在推文里给的模板：

    品质前缀 → 1girl, solo → 固定行（发型 / 发色 / 刘海 / 发饰 / 眼睛 / 体型）
    → 表情 → 服装 → 姿势 → 构图 → 背景 → 追加标签

- 固定行：同一角色 300 页里一个字都不改
- 可变行：每张图最多改 3 个（服装、姿势、表情）
- 姿势标签里出现 2girls 时，会自动把 1girl, solo 换成 2girls, multiple girls
