Quick Start

Each command below is self-contained: open PowerShell, copy it, paste it and press Enter.

1. Download mcp-for-blender-pro.zip from [Releases.
2. In Blender, open Edit → Preferences → Get Extensions → menu → Install from Disk.
3. Select the ZIP, enable mcp-for-blender-pro, then open 3D Viewport → N → MCP Pro.
4. Choose a provider, add your connection details and select a model.
5. Send a message in Blender or click Open Studio Window.

Features

- Search three libraries mid-conversation—Poly Haven, Sketchfab and Poly Pizza.
- Confirm before importing—nothing lands in the scene without your approval.
- Respect the licenses—asset terms are surfaced with the results so usage stays clean.
- Store service keys once—per-service keys live in user settings, not in every tool.
- Compose assets into scenes—the same 27 tools arrange, light and material around what you import.
- Inspect what you already have—existing objects are read before anything imports.
- Serve the toolset over MCP—external clients search and import through the same endpoint.

How it works

blender-ai-copilot-assets runs inside Blender as an extension: the copilot inspects your scene, searches the configured libraries for what the brief needs, and imports the chosen asset as an approved operation—then continues building, lighting and materializing around it with the 27 supervised scene tools. The whole flow is exposed to OpenCode and other compatible clients through a local authenticated endpoint (http://127.0.0.1:9876/mcp).

Usage

A matched environment. "Find an appropriate Poly Haven asset for this scene and ask before importing it." Compare the shortlist, approve the pick, and let the copilot place and light around it.

A license-clean import. Ask for the asset's terms before approving—the copilot surfaces them with the result, so nothing enters the scene unlicensed.

Assets plus build. Import the model, then keep going in the same chat: pedestal, three-point light, matte material, viewport snapshot—one brief, one flow.

Configuration

| Setting | Default | What it does |
|---|---|---|
| Asset services | Poly Haven, Sketchfab, Poly Pizza | Search and import across the three libraries |
| Service keys | Optional | Keys for providers that require them, stored in user settings |
| Import approvals | Per asset | Every import waits for your confirmation |
| Workflow mode | Single assistant | Plain chat or a Team chain for larger builds |
| Provider | OpenAI | OpenAI, Anthropic Claude, Google Gemini, OpenRouter, OpenCode Zen, Ollama or Custom API |
| Model | Provider catalog | Pick a tool-calling model; enter the model ID manually when needed |
| MCP endpoint | http://127.0.0.1:9876/mcp | Local Streamable HTTP endpoint for external MCP clients |
| Access token | Generated when enabled | Bearer token for the MCP endpoint |
| Interface language | English | English, German, French, Spanish or Chinese |

Troubleshooting / FAQ

A service returns no results. Check the service key in preferences for that provider—some libraries require a key even for free assets.

Where did the import land? Imports are placed by the scene tools as approved steps; ask the copilot to reposition if the spot is wrong.

Can I use the assets commercially? Follow each asset's license—the copilot surfaces the terms, but the usage decision is yours.

Does search interrupt the build? No—search, build and light run in the same conversation with the same approvals.

Can external clients import assets? Yes—through the MCP endpoint, with the same supervised tool calls.
