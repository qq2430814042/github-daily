🎙️ VoiceStudioV2

Local AI voice studio — real-time voice changer, text-to-speech, voice cloning and dubbing, with a drop-in OpenAI-compatible API.

100% local. No cloud. No API keys. Your voice never leaves your machine.

Unofficial fork. VoiceStudioV2 is a community fork of debpalash/VoiceStudio. It is not affiliated with or endorsed by the upstream authors.

✨ What is VoiceStudioV2?

VoiceStudioV2 is a desktop app that puts a full voice toolkit on your own computer: speak in a different voice live, turn text into natural speech, clone a voice from a short sample, dub video into other languages, and plug it all into your favorite tools through an OpenAI-compatible API.

Everything runs on your hardware. No subscriptions, no per-character billing, no uploads.

🚀 Quick start

1. Install VoiceStudioV2 from the table above.
2. Open the app and pick a model from the Model Catalogue. The first launch downloads the model you choose.
3. Try it:
   - Type some text and press Generate for text-to-speech.
   - Open Real-time voice, choose your microphone and output device, and start talking.
4. Optional: enable the local API server in Settings → API to use VoiceStudioV2 from other apps.

⚡ Real-time voice

Speak into your microphone and hear yourself in a different voice, live.

How to use it
1. Open the Real-time voice workspace.
2. Select your input (microphone) and output device.
3. Choose a voice or a cloned voice.
4. Press Start and talk.

Using it in other apps (Discord, OBS, games, calls)
Route the output to a virtual audio cable and select that cable as the microphone in the target app.

| OS | Virtual audio device |
|---|---|
| Windows | VB-CABLE |

Tips for low latency
- Use a wired headset or a low-latency audio interface.
- Prefer a lightweight model for live use.
- Run on a GPU if you have one.
- Close other heavy apps while streaming.

Mapping models and voices

Clients send OpenAI names such as tts-1 and alloy. VoiceStudioV2 maps them to local engines and voices, so you decide what actually answers.

| OpenAI name | Runs locally as |
|---|---|
| tts-1 | your default engine |
| alloy, echo, … | your voices / cloned voices |

Works with

Any app that lets you set a custom OpenAI base URL can use VoiceStudioV2 as its voice backend: chat frontends, automation tools, bots, readers and scripts. Typical examples are SillyTavern, Open WebUI, n8n and your own code. Check the target app's settings for "OpenAI-compatible" or "custom endpoint".

🧩 Supported engines

VoiceStudioV2 inherits the engine catalogue of upstream VoiceStudio. Engines and models are installed from the in-app Model Catalogue and can be switched at any time.

❓ FAQ

Is it really free and offline?
Yes. Models run on your computer. Internet is only needed to download the app and models.

Do I need a GPU?
No for lightweight models. A GPU helps a lot with larger models and with real-time use.

Can I use it with my own apps?
Yes. Use the OpenAI-compatible API and set a custom base URL.

Does it work in Discord / OBS / games?
Yes, via a virtual audio cable. See Real-time voice.

How is this different from upstream VoiceStudio?
V2 adds real-time voice and an OpenAI-compatible API on top of the upstream app. See What's new in V2.

The app says my antivirus / SmartScreen blocked it.
Builds may be unsigned. Download only from this repository's Releases page, then use More info → Run anyway.

⚠️ Responsible use

Voice cloning and voice changing are powerful. Use them only with voices you own or have explicit permission to use. Do not use this software for impersonation, fraud, harassment or misleading content. You are responsible for complying with the laws that apply to you.
