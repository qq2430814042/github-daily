Modules and Settings

Stash Marker Module
This module gives the user a live external view of stash positions so hidden caches can be judged relative to the current location in a Rust-style sandbox.
- Display range controls how far away a stash is still drawn, letting the user keep the overlay relevant to the immediate area or widen it while scouting.
- Marker style settings switch between different label and icon treatments so stash entries remain distinguishable from other overlay elements.
- Layer visibility can be toggled on its own, so stash markers can be hidden while the rest of the overlay stays active.

Tool Cupboard Module
The tool cupboard module reports TC placements and their approximate coverage so the user can plan movement before entering protected zones.
- Coverage view selects between outline-style zone indications and compact markers, depending on how much of the screen the user is willing to give up.
- TC layer toggle hides the cupboard information independently of stash and player readouts.
- Placement labelling settings control how much identifying detail accompanies each cupboard entry.

Nearby Player Module
This module lists detected players inside a configurable range, providing direction and distance cues rather than an unqualified count.
- Range threshold sets the distance at which players are still listed, keeping the readout focused on nearby activity.
- Sort order rearranges entries, for example by distance, so the closest contacts are readable first.
- Label detail settings adjust how much information appears per player, from direction cues alone to fuller entries.

Filter and Preset Module
This module removes irrelevant entries so the overlay shows only the information the user currently needs.
- Distance-based filters suppress distant stashes or players beyond a chosen radius.
- Category filters hide whole groups, such as excluding player entries while keeping stash markers visible.
- Saved presets store filter combinations and can be switched between sessions without rebuilding the setup.

Display and Profile Module
This module handles the visual presentation of the overlay and keeps separate setups for different activities.
- Colour, opacity, marker size and text scale settings keep the readout legible across monitors and lighting conditions.
- Layer ordering and collapsing controls place the most important readouts where the user expects them.
- Session profiles bundle layer toggles, filters and display settings, and can be loaded at startup so the overlay opens in the expected state.

Process Status Module
This module keeps the external companion transparent about whether the game process is detected and whether the overlay is attached.
- Status indicators show the current attachment state instead of failing silently.
- A reattach control restores the connection after a drop without restarting the whole tool.
- Warning messages surface connection problems so troubleshooting stays predictable during a session.

Additional Settings
- Hotkey bindings assign overlay layers and profiles to user-defined keys, with conflicting assignments flagged in the settings view so changes are immediate and unambiguous.
- Startup profile selection determines which saved configuration the overlay opens with.
- Persistent settings keep layer, filter and display choices between sessions.
- In-view warning display controls how prominently status messages appear, so attachment issues can be noticed without obscuring the game view.
