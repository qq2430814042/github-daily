脱敏

妈妈再也不用担心我被按头了。

脱敏是一款运行于 Android 平台的截图隐私处理工具。用户可通过相册导入截图，或将图片从其他应用直接分享至脱敏。应用基于本地识别能力检测手机号、邮箱、账号、订单号、证件信息、姓名、学校、公司、地址、二维码、条形码及公章等隐私候选，并提供不透明矩形、圆形和画笔遮挡，最终导出已移除 EXIF、位置及设备信息的分享图片。

应用无需登录，不上传原图，全部识别与处理均在设备本地完成。

核心能力

- 本地识别：采用规则引擎、中文 OCR、量化中文 NER，以及二维码、条形码和印章检测。
- 微信字段识别：支持微信号、WeChat ID、VX、v信等字段变体，并兼容换行和 OCR 空格。
- 快速脱敏：支持一键打码全部候选，也可逐项查看并补充手动遮挡。
- 暗水印处理：提供暗纹可视检查、自动抹除和底图同色手动覆盖。
- 隐私存储：本地项目使用 Android Keystore 与 AES-GCM 加密，支持应用锁和无痕模式。
- 安全导出：重新绘制图片、移除元数据，并在导出后再次检查可能残留的敏感内容。

隐私设计

发布包不包含 INTERNET 或 ACCESS_NETWORK_STATE 权限，不接入广告或分析 SDK。构建过程会检查合并后的权限、依赖和本地 NER 模型哈希。

存在未确认候选或未完成遮挡时，应用会显示“目前还未完全脱敏”提示，并允许用户继续导出。

技术栈

- Kotlin + Jetpack Compose
- Android Canvas
- Google ML Kit（本地文字、二维码、条形码与人脸检测）
- ONNX Runtime Mobile + 量化中文 NER 模型
- Android Keystore + AES-GCM

最低支持 Android 10。

构建

需要 JDK 17 和 Android SDK 35。

.\gradlew.bat :app:assembleDebug

调试 APK 输出到 app/build/outputs/apk/debug/app-debug.apk。

运行单元测试：

.\gradlew.bat :app:testDebugUnitTest
