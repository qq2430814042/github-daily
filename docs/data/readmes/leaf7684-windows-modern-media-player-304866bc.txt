Modern Windows Media Player is a free, open-source video and audio player for Windows 10 and Windows 11. Built around VLC playback technology and a clean Windows interface, it makes watching movies, listening to music, streaming network media, and managing playback simple — without requiring a command line.

⬇️ Installation

Download the Windows application

1. Open the repository's Releases page.
2. Download the latest release archive Modern Windows Media Player 4.4.5.zip.
3. Extract the archive into a folder of your choice.
4. Keep Modern Windows Media Player 4.4.5.exe and libvlc.dll together in that folder.
5. Double-click Modern Windows Media Player 4.4.5.exe to launch the application.

✨ Features

Everything you need for a comfortable desktop media playback experience.

- 🎬 Universal Video Playback — Play a wide variety of video formats using the powerful VLC-based media engine.
- 🎵 Audio File Support — Enjoy music and audio files with convenient playback controls and an intuitive interface.
- 🪟 Modern Windows Interface — Experience a clean, Fluent-inspired desktop design with layouts adapted to different screen sizes.
- 📺 Picture-in-Picture Mode — Keep videos visible in a compact floating player while working in other applications.
- 🌐 Network Media Streaming — Browse supported network locations and play media stored on other devices.
- 📡 Chromecast Support — Send compatible media to supported Chromecast devices for playback on a larger screen.
- ⌨️ Keyboard Shortcuts — Control playback, volume, seeking, and window size using convenient keyboard commands.
- 👆 Touch and Gesture Controls — Navigate playback and adjust volume using intuitive touch-friendly interactions.
- 📸 Video Frame Capture — Save individual video frames as image files directly from the player.
- 📐 Flexible Window Sizing — Adjust the playback window quickly with dedicated keyboard shortcuts.
- 🎞️ Subtitle Support — Enjoy supported subtitle tracks and a more accessible viewing experience.
- ⚡ Hardware-Accelerated Playback — Benefit from supported video acceleration capabilities offered by the underlying playback platform.

🎥 Media Playback Technology

The player uses the VLC ecosystem through LibVLCSharp, bringing established media playback capabilities into a native-feeling Windows application.

Key technology components:

- C# and .NET — Application development and core functionality.
- Universal Windows Platform (UWP) — Windows application framework.
- LibVLCSharp — .NET bindings for VLC media playback.
- libVLC — Underlying multimedia playback engine.
- Fluent-inspired UI — Consistent Windows-oriented interaction and visual design.

This architecture provides a foundation for flexible media playback without requiring users to configure a separate command-line media tool.
