🎯 What it is

Roblox Performance Tool is a native utility for players who want smoother gameplay.
It safely adjusts system priorities and removes the default frame rate cap, which causes stuttering and input delay on modern monitors.

🛡️ Safe by design: It does not inject code into the game, does not modify memory, and does not bypass anti-cheat. It only adjusts the frame rate limit and system priorities.

🛠️ How to use

1. Launch the application.
2. Set your desired FPS limit in the interface (or leave it at 0 for unlimited).
3. Click "Apply".
4. Launch Roblox. The performance boost is now active.
5. To restore default settings, click "Reset" in the app.

⚙️ Configuration

You can adjust settings in the config.ini file:

- FPS Limit: 0 for unlimited, or any number (e.g., 144, 240)
- Performance Mode: High priority for the Roblox process
- Auto-Start: true or false
- Minimize to Tray: Keep the app running in the background
- Check for Updates: Enable/disable update notifications

❓ FAQ

Is this safe to use?
Yes. The tool only changes the frame rate limit and process priority. It does not interact with the game's memory or anti-cheat systems. Thousands of players use similar tools daily.

Does it work on Mac or Linux?
Currently, the tool is exclusive to Windows 10 and 11.

Do I need to keep the app running?
No. Once you apply the settings, you can close the app. The performance boost remains active until you reset it or Roblox updates.

Why does my FPS drop after an update?
Roblox updates sometimes reset the FPS cap. Simply run the tool again and click "Apply".

💻 Tech Stack & Architecture
