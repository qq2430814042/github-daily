❓ FAQ

🔸 Vanguard blocks the launch, what should I do?

Make sure you are using the latest version of the loader. If the issue persists, reboot your PC and run the loader before launching Valorant.

🔸 FPS drops after injection?

Disable any ESP modules you don't use (Skeleton, Glow). Keep only Boxes + Names for minimal overhead.

🔸 Can I stream with the software running?

The overlay is rendered via DirectX and is not visible when captured through OBS (Game Capture). However, we do not recommend doing this.

🔸 How do I update after a Valorant patch?

The loader checks for updates automatically. If the software goes down after a patch, wait 12–24 hours for a fix. Follow our Discord for announcements.
