SnowLuma

让 QQ 原生会话，连接你的应用。

QQ 客户端的 TypeScript 互操作运行时。

OneBot v11 · WebUI · SDK · MCP

将 QQ 原生会话转换为 OneBot v11 动作与事件，通过 WebSocket、HTTP、WebUI、SDK 和 MCP 提供统一入口。

多账号会话、消息与媒体、连接配置和实时日志，在一个运行时中管理。

下载发行版 · 快速开始

核心能力

| 场景 | 能力 |
| --- | --- |
| OneBot 接入 | OneBot v11 动作与事件；WebSocket 服务端 / 客户端及 HTTP 服务端 / 上报 |
| 消息与媒体 | 文本、图片、语音、视频、文件、回复、提及、转发及常见卡片 |
| 多账号运行 | 各账号独立维护会话、身份映射、消息存储和网络配置 |
| WebUI 管理 | 账号状态、实时日志、连接配置、动作调试和存储管理 |
| 开发者工具 | @snowluma/sdk 与 @snowluma/mcp |

运行链路

会话接入、协议解析、身份映射、OneBot 转换和网络适配保持独立边界；多个 QQ 账号可并行运行。

快速开始

1. 从 Releases 下载对应平台的完整发行包并解压。Lite 版需 Node.js 24+。
2. Windows 运行 launcher.bat；Linux 执行：

   chmod +x launcher.sh
   ./launcher.sh

3. 打开 http://localhost:5099，使用启动日志中的初始密码登录 WebUI，按引导接入 QQ 进程并配置 OneBot 连接。

账号识别由登录数据库的文件变化、进程和登录事件或手动操作触发，不做周期探测。未载入的 QQ 进程也不会持续调用 Windows Restart Manager；需要重查时可点击 WebUI 进程行的刷新/重连。

开发

需要 Node.js 24+ 与 pnpm 11.25.0，日常开发基于 dev 分支：

git clone https://github.com/SnowLuma/SnowLuma.git
cd SnowLuma
git checkout dev
pnpm install --frozen-lockfile
pnpm typecheck
pnpm test

贡献流程见 CONTRIBUTING.md；模块边界与项目词汇见 CONTEXT.md；开发方向见 RoadMap.md。
