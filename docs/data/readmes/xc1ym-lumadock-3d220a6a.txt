LumaDock is a native Switch game launcher for Apple Silicon Macs. With the bundled nxnative engine, your authorized NSP/XCI files and prod.keys, import games, prepare and launch them on Mac, or export an unsigned iPhone / iPad IPA.

nxnative provides native execution and Metal graphics; LumaDock provides the library and graphical workflow. The engine is included; games, updates, DLC, firmware, keys, game artwork and player caches are not.

nxnative is synchronized from upstream daily, with automated tests before repository updates. To use the latest synchronized engine, build the App or DMG yourself. Releases provide only the DMG, on demand, not daily.

Switch Pro, Xbox and PlayStation controllers use native GameController input: Switch A / Xbox A / PS cross → game A, with no manual key mapping. Prepare existing games again to apply the new engine.

Features

- Library management — Add NSP/XCI/NSZ/XCZ files or scan a folder; import NSP/XCI directly, decompress NSZ/XCZ, then prepare automatically.
- Automated builds — Prepare code, shaders and runtime files with validated caches, cancellation and retry.
- Save protection and version rollback — Create and verify save backups, restore saves, and switch between prepared runtime versions with an automatic save backup before switching.
- File conversion — Convert NSP/XCI, compress or decompress NSZ/XCZ, and merge packages using bundled conversion tools adapted from SAK-Mac. Exported NSPs can be imported into the library.
- IPA export — Generate an unsigned iPhone / iPad package from game details.
- Visible progress and errors — Follow measured progress, milestone steps and reference time estimates; get shader warnings, repair suggestions, specific logs and redacted error summaries.
- Native Mac experience — English / 简体中文, light / dark appearance, game-language settings and input mapping where supported by the selected engine.

Get started

Requirements: Apple Silicon and macOS 26+. Preparing games also requires full Xcode with Metal. nxnative, the reader, shader translator and runtime dependencies are included in packaged apps.

1. Download the latest ARM64 DMG, verify its SHA-256 against the Release notes, and drag LumaDock.app into Applications. Current builds use ad-hoc signing and are not notarized.
2. Follow setup: check the environment and choose Prepare engine tools; no separate engine download is needed.
3. Choose a library, import your own prod.keys, then add the base game, updates and DLC as NSP, XCI, NSZ or XCZ files.
4. Prepare the game and choose Launch game, or choose Generate IPA… in game details. Tasks show progress and support cancellation and retry.

IPA export additionally requires Xcode's iOS platform and XcodeGen (brew install xcodegen). Sign the exported IPA with your installation tool before installing it.

Compatibility depends on the selected engine and game version. Successful preparation does not guarantee full gameplay compatibility; iOS device compatibility has not been validated. Back up saves before upgrades or experiments.
