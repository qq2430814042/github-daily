易经 · 六十四卦结构动画

I Ching 64 Hexagrams — a motion-graphics film made entirely with code

这是一部关于 《易经》六十四卦 的知识动画，全长约 3 分钟。

画面全部由代码生成：React + SVG + three.js，用 Remotion 渲染成视频。配乐由 Python 程序合成，没有使用任何外部图片、视频或音频素材。

《易经》又称《周易》，英文通常写作 I Ching 或 Yijing（"I Ching" 是"易经"二字的旧式拼音）。它是中国最古老的典籍之一，被尊为"群经之首"。

什么是《易经》

| 层次 | 内容 |
|---|---|
| 爻 | 最小单位只有两种：阳爻 ⚊（一条整线）和阴爻 ⚋（一条断线）。|
| 八卦 | 三条爻叠在一起，有 2³ = 8 种组合：乾 ☰、兑 ☱、离 ☲、震 ☳、巽 ☴、坎 ☵、艮 ☶、坤 ☷。分别象征天、泽、火、雷、风、水、山、地。|
| 六十四卦 | 两个八卦一上一下相重，即六条爻，有 2⁶ = 64 种组合，每一卦代表一种处境，如乾、坤、屯、蒙……未济。|
| 三百八十四爻 | 64 卦 × 6 爻 = 384 爻，每一爻都有爻辞；加上乾卦"用九"、坤卦"用六"，共 386 条。|
| 经与传 | "经"指卦画、卦辞、爻辞，传统认为成书于西周。"传"指解释经文的十篇《易传》（"十翼"）：彖上下、象上下、系辞上下、文言、说卦、序卦、杂卦。|

阴爻记作 0、阳爻记作 1，每一卦就是一个 6 位二进制数（0–63）。1703 年，莱布尼茨在讨论二进制的论文中专门谈到了宋代邵雍排定的伏羲卦序。

这部片子不讲占卜，讲的是六十四卦这套符号系统本身的数学与结构。

片中讲了什么

全片分为七章，同一组 64 卦用七种方式去读：

1. 生成
   - 太极 → 两仪 → 四象 → 八卦 → 十六 → 三十二 → 六十四（邵雍"加一倍法"）。
   - 另一种生法：八卦相重，8 × 8 = 64。
   - 八卦的象、性、家人、身体与动物（《说卦传》）；阴 0 阳 1 的二进制读法；384 爻。
2. 方圆
   - 伏羲六十四卦圆图与方图：乾南坤北，阳生于复，阴生于姤。
   - 方图从外到内分为乾坤、兑艮、离坎、震巽四层；泰与否位于方图对角。
   - 圆图上相对的两卦互为错卦，共 32 对。
3. 错综
   - 错（旁通）：六爻阴阳全部翻转，如屯错为鼎。
   - 综（反对）：整卦倒过来看，如屯综为蒙。
   - 文王卦序"二二相耦，非覆即变"：28 对综、4 对错。
   - 倒过来仍是自己的 8 卦；"三十六宫都是春"（56 ÷ 2 + 8 = 36）。
4. 互变
   - 互卦取中间四爻：屯 → 剥 → 坤；64 卦反复取互，收缩为 16 卦，再收缩为 4 卦（乾、坤、既济、未济）。
   - 变卦：64 卦是六维立方体的 64 个顶点，改变一爻就是沿一条边走一步。
   - 九、六为动爻，七、八不动；本卦到之卦共 64 × 64 = 4096 种。
5. 序卦
   - 沿文王卦序走完 64 卦，配《序卦传》原文："有天地然后万物生焉""物不可穷也，故受之以未济，终焉"。
   - 上经 30 卦讲天道，下经 34 卦讲人事。
6. 消息
   - 十二消息卦对应十二个月：复为冬至一阳生，姤为夏至一阴生。
   - 一年的阴阳消长就是一条连续的轨迹。
7. 八宫
   - 京房八宫：本宫 → 一世…五世 → 游魂 → 归魂。
   - 世应相隔、八宫五行，八宫之下 64 卦一卦不漏。

技术

- 视频框架：Remotion 4（用 React 写视频），每一帧都是时间的纯函数。
- 画面：SVG 和 three.js，卦象、圆图、方图、六维立方体投影等全部由数据生成。
- 配乐：gen_music.py 用 numpy/scipy 合成，按画面事件的时间表发声，每章使用不同配器。
- 数据：六十四卦、八宫、卦序等都由定义推导生成（src/g/data.ts），不手工抄写。

运行

需要 Node.js 18+，配乐部分需要 Python 3（numpy、scipy）。

npm install

在浏览器里实时预览
npm run studio

生成配乐 → public/music.wav（不生成也能预览，只是没有声音）
npm run music

渲染成片 → out/iching-64-motion.mp4
npm run render
