Blender AI MCP Suite
Blender AI MCP Suite is an AI assistant and built-in Model Context Protocol (MCP) server for Blender that turns plain-language briefs into inspected, approved and reversible 3D scene operations — with a visual Studio workspace, multi-agent teams, 21+ scene tools and your choice of AI models.

Picture the workflow: you type "Build a night product stage with a pedestal, a camera and three lights" — the assistant inspects the scene, plans ordered steps, places the pedestal, aims the camera, sets the lights, applies a matte blue material and returns a viewport screenshot for review. Every step is approved in chat, every change is reversible through a named undo checkpoint, and the scene is export-ready when you are.

Why

3D work is full of mechanical steps — arranging props, tuning materials, re-exporting variations — while generic chat tabs cannot see your scene and blind scripts edit without review. Blender AI MCP Suite puts the assistant inside Blender: it inspects the scene first, then builds, edits and exports through a validated tool set you approve step by step, with undo checkpoints on every mutation. You iterate at the speed of conversation and keep full creative control.

Quick Start

1. Download mcp-for-blender-pro.zip from Releases.
2. In Blender, open Edit → Preferences → Get Extensions → menu → Install from Disk.
3. Select the ZIP, enable mcp-for-blender-pro, then open 3D Viewport → N → MCP Pro.
4. Choose a provider, add your connection details and select a model.
5. Send a message in Blender or click Open Studio Window.

Features

- Inspect the scene before acting — objects, transforms, materials and modifiers give the assistant real context.
- Build and edit through conversation — primitives, lights, cameras, parenting, duplication and materials arrive as approved steps.
- Verify results visually — viewport screenshots let vision-capable models check their own work.
- Run one assistant or a full team — manager, workers and reviewers with individual instructions and models.
- Connect your choice of AI — OpenAI, Anthropic Claude, Google Gemini, OpenRouter, OpenCode Zen, local Ollama or custom endpoints.
- Search and import assets in chat — Poly Haven, Sketchfab and Poly Pizza results with import approval.
- Automate and export — bpy API lookups, node descriptions, validated Python execution and scene export, all reversible via named undo checkpoints.

How it works

Blender AI MCP Suite runs inside Blender as one extension with three cooperating parts: the AI Suite sidebar (chat, scene outline, viewport snapshots, approvals and the task board), the connection manager (saved providers, keys and models, kept separate for work and personal use) and the built-in MCP server (an authenticated local Streamable HTTP endpoint for external clients). A brief is inspected through 21+ scene tools, split into ordered steps that run one by one — each visible, approved and reversible — while larger jobs are delegated to a manager, workers and reviewers; external clients such as OpenCode drive the same tool set through the MCP endpoint.

Usage

- Product stage in one message. Ask: "Create a product-display scene with a pedestal, a camera and three lights; give the pedestal a matte blue material." Approve the steps as they run and export the scene when the reviewer signs off.
- Batch arrangement with visual proof. Ask: "Duplicate the selected object into a neatly spaced row of five and show the viewport." The assistant duplicates, aligns and returns a screenshot to confirm the result.
- Structured agent chain. Hand a bigger brief to a team: the manager splits it into assignments with acceptance criteria, workers perform the scene operations, reviewers approve or return findings, and the task board tracks every attempt.

Troubleshooting / FAQ

The add-on does not appear after installation. Confirm you are running Blender 4.2 or later on Windows x64, reinstall via Edit → Preferences → Get Extensions → menu → Install from Disk and enable Blender AI MCP Suite.

Windows blocked the downloaded ZIP. Right-click the archive, open Properties, check Unblock and confirm, then install it again.

The assistant does not answer or changes nothing. Check the saved connection details and key, select a model with tool-calling support, and approve the pending operation in the chat.

An external MCP client cannot connect. Keep Blender open while using Studio or external clients, confirm the client supports authenticated Streamable HTTP MCP, and copy the endpoint exactly as shown in the sidebar.

A team task stopped. A blocked task gets one correction attempt; a second failed review stops the workflow — open the task board, read the findings and resume from the last approved step.

Where do credentials live? In your user settings on your own machine; chat history lasts for the current session. Python tool validation is a guardrail, not a security sandbox.
