🎯 Valorant ESP

Advanced Player Visual Overlay — 2026

High-performance Valorant ESP focused on clear and customizable player visuals.
Clean modular structure, fully configurable and easy to use.

🎯 What it is

Valorant ESP is a lightweight overlay that displays player boxes, names, health bars, distance and skeleton.
Built for stability and compatibility with the current Valorant patch.

⚠️
Use at your own risk. This is an open-source educational project.

✨ Features

| Feature                  | Description                                      |
|--------------------------|--------------------------------------------------|
| 📦 Box ESP           | Clean 2D/3D player boxes                         |

🧩 How to use

1. Launch the tool.
2. Configure your ESP settings.
3. Join a Valorant match.
4. Toggle the overlay on/off with the hotkey.

⚙️ Configuration

All settings can be changed in the config:

- Box style and color
- Name display
- Health bar
- Distance
- Skeleton
- Hotkeys
