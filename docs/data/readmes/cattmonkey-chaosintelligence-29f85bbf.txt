把智能体当函数，把想法写成程序。

Chaos 是一门以函数为基础、把智能体作为可调用值的编程语言。 计算与流程写成函数，理解与生成交给智能体；让它们在同一个程序里传递数据、协作执行、返回结果。

一份 .chaos 源码，从终端到网页 IDE，再到已有工程。你可以从一个小函数开始，逐步构建有目标、能交互、可观察的智能系统。

三个小例子，看懂这门语言

1. 普通计算，先从 42 开始

fn twice(f: Function, x) { f(f(x)) }
fn add_one(x: Int) -> Int { x + 1 }

twice(add_one, 40)

结果是 42。函数可以作为参数，最后一个表达式就是程序结果。保存为 hello.chaos，执行 ./chaos run hello.chaos。纯计算无需网络与模型密钥。 函数组合 →

三步开始，在自己的目录里用

需要 Python 3.9+；日常编程使用语言自己的命令。macOS／Linux 使用 ./chaos，Windows PowerShell 使用 .\chaos.cmd。

1. 从最新发行版下载 Chaos-Project.zip，解压到新目录并打开终端。
2. 执行 ./chaos run，运行自带程序，确认得到 42。
3. 执行以下命令，配置环境并打开当前目录的 IDE：

   ./chaos setup --yes
   ./chaos

setup 检测环境、安装项目内依赖并运行自检；按终端打印的实际地址进入网页。包不包含 Python，首次完整配置需要可访问的 Python 包来源。快速开始 →

喜欢终端？可以全程不用网页

./chaos -c '40 + 2'
./chaos run main.chaos
./chaos repl --empty
./chaos ask '给我一个函数组合的短例子' --topic getting-started --stream

ask 需要配置模型，流式回答且不修改文件；IDE 助手或 assist 可生成代码修改提案。命令行教程 →

更新时保留自己的程序

完整包替换、校验与回退

取得新版完整 project ZIP 或 portable ZIP，停止本项目的 IDE 与程序，在原工程执行：

./chaos replace "/absolute/path/Chaos-Project-New.zip"
./chaos status

更新先校验与试运行，再切换环境，保留项目源码、配置与数据；./chaos rollback 可恢复上一环境及配套依赖。若 dependenciesReady 为 false，按提示运行 ./chaos setup --yes。不要把新版 ZIP 直接覆盖解压到旧工程。更新与回退 →
