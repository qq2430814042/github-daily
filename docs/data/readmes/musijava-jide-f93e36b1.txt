JIDE

中文 | English

JIDE 是面向 Android 的 Java 集成开发环境。它以设备上的项目目录为工作区，在应用内完成代码编辑、项目分析、编译和运行，也可以将项目打包为标准 JAR。项目使用普通文件目录和 JAR 依赖，源码、资源与构建产物均可在文件系统中访问。

Java 编辑与代码分析

- 语义补全支持根据项目源码和依赖补全类型、成员和包名，并提供方法参数提示与自动导入。默认使用 Eclipse JDT，也可在设置中切换到 JIDE 的自研引擎。
- 诊断与导航支持在编辑器中查看错误和警告、应用可用的快速修复，并通过项目检查定位其他文件中的问题。可在项目源码中跳转到声明、查找用法和查看方法使用次数。
- 代码整理使用 Eclipse JDT 格式化 Java 源码，可调整缩进、空格、换行和括号等规则。编辑器还提供 import 清理、正则查找替换、括号匹配、代码折叠和代码块对齐线。
- 触屏编辑支持多标签、标签置顶、撤销重做、双指缩放、软键盘快捷栏和深色主题。可配置定时自动保存与切到后台时自动保存。外部程序修改已打开的文件后，返回 JIDE 时可选择重新读取文件或保留编辑器中的内容。

行内续写

行内续写默认关闭。配置兼容 DeepSeek FIM（Fill-in-the-Middle）的 HTTPS 接口、模型和 API 密钥后，可在编辑器中流式预览续写内容，使用 Tab 采纳。生成设置包含流式输出开关、内容过滤（校验重复声明与语义错误）、续写进度条、触发延迟，以及输入与输出的 token 上限。启用后，相关代码上下文会发送至所配置的服务。

项目、运行与 JAR 打包

项目配置保存在根目录的 jide.json 中，源码目录和 JAR 依赖目录默认为 src/ 和 lib/，可在「项目配置」中调整。

- 设备端运行使用 ECJ 编译源码，并由 Android Runtime（ART）执行。控制台提供标准输入，显示标准输出与错误输出，也可中止当前运行。
- 入口类选择在运行时优先使用当前文件中可运行的入口。运行和打包共用上次确认的入口记录，类仍在候选列表中时会默认选中。
- JAR 打包生成 out/项目名.jar。没有入口类的项目可打包为库 JAR。需要附带依赖时，构建会生成同目录的 项目名.lib/，由 JAR 清单通过相对路径引用。移动产物时需保留两者的相对位置。
- 运行参数通过 vmOptions 配置。应用内运行支持 -D 系统属性。生成可执行 JAR 后可复制 OpenJDK 启动命令。

Git 工作区

Git 面板包含「更改」「历史」「参与文件」和「配置」四页，可直接在项目内完成常用操作。

- 初始化仓库、查看工作区差异和提交历史，以及管理本地分支。
- 按文件或目录设置参与范围，在提交表单中选择本次要提交的已保存文件。
- 通过 HTTPS 克隆、拉取和推送。拉取仅支持快进。已有待推送提交时，右侧操作显示「推送」。没有待推送提交但有可提交的改动时，右侧操作显示「提交并推送」。

数据库工具

数据库面板可连接 MySQL 或 MariaDB，表数据和 SQL 控制台与源码使用同一标签栏。JDBC 驱动可按需下载或导入。

- SQL 控制台可执行选中的 SQL 或光标所在语句，支持根据数据库结构提示表名和字段名，也可取消正在执行的查询。查询结果与执行输出分别显示，结果支持分页浏览。
- 表数据支持分页、WHERE 条件、ORDER BY 排序和列值筛选。可编辑的表支持暂存新增、修改和删除，暂存操作可撤销、重做，再提交至数据库。视图或缺少可用主键的表可只读浏览。
- 表结构与导出支持查看字段、键和索引，创建表，修改表结构及预览待执行的 SQL。SQL 文件可仅导出结构，也可同时包含数据。

设置

兼容性

| 项目 | 要求 |
| --- | --- |
| 应用 | Android 5.0（API 21）及以上，项目目录需对应用可读写 |
| Git | Android 8.0（API 26）及以上 |
| Java 语言级别与字节码目标 | Java 8、11、17 或 21，默认 17 |

设备上的 Java SE API 可用范围由 Android 系统和 JIDE 的兼容层决定。生成带入口类的 JAR 后，也可在满足项目依赖的 OpenJDK 环境中运行。

创建和运行项目

1. 安装 JIDE APK。从源码生成 APK 的步骤见构建说明。
2. 在右上角菜单选择「创建项目」。新项目位于共享存储的 JProjects/ 目录下，包含示例入口 src/Main.java。
3. 在文件树中打开 Main.java，点击工具栏的运行按钮。示例程序在控制台输出 Hello, JIDE!。

使用已有项目时，在菜单中选择「打开项目」，指定项目根目录并根据目录结构检查「项目配置」。
