趋势判断工作台

我是 DeFi狙击手。我做了一个本地看盘工具，把加密货币、美股和 A 股放在同一个窗口。搜到标的，选好周期，就能看到过去的走势如何分笔、哪里形成了中枢，以及接下来哪些价位值得观察。

打开后怎么看

以 BTC/USDT 为例。切到日线，如果看到 日线偏空 · 周线偏多，意思是日线结构在走弱，放到周线上看，结构仍然偏强。图上的入场区间、止损和两档止盈都按你选中的日线计算。切到 1 小时，就重新按小时线计算。这个例子用来解释界面，实际方向会随行情变化。

| 想看什么 | 工作台能做什么 |
| --- | --- |
| 一个标的过去怎么走 | 按代码、币种或公司名搜索。支持 1、5、15、30 分钟，1、4 小时，以及日、周、月线。公开行情源能提供的历史长度因标的和周期而异。 |
| 趋势从哪里起、在哪里反复 | 在 K 线上叠加分型、笔、线段、中枢和历史信号。笔中枢看局部重叠，线段中枢看更大一段走势，两层可以单独开关。 |
| 后面看哪些价位 | 结构足够清楚时，查看做多或做空方案的入场区间、触发条件、止损和两档止盈。方向待明时先看支撑和阻力。 |
| 这个方向有多少依据 | 对照缠论结构、MACD 动能、相对成交量和更大周期。多空百分比表示当前结构倾向；例如“多方 70%”描述的是评分，不能据此推算十次交易会赢七次。 |
| 当时能不能看出这个走势 | 用历史回放逐根推进 K 线，观察当时可见的结构。可导入自己的 OHLCV CSV，也可导出 K 线和分析结果复盘。 |
| 怎样一起看多个标的 | 加入自选，按当前周期开启监测。每轮最多检查前 12 个自选，两轮至少间隔 60 秒，只提示新变化。关闭工作台，监测随之停止。 |

加密货币连续交易，确认条件里的“K 线结束”指所选周期走完。股票按交易时段处理，4 小时线按交易所时段聚合。数据不足或行情过期时，界面会说明原因。工作台提供价格参考，交易由使用者自己决定和执行。

下载和使用

在 Releases 选对应系统的 ZIP。两版都叫「趋势判断工作台」，默认中文，可切换英文。

| 系统 | 打开方式 |
| --- | --- |
| Windows 10/11 x64 | 完整解压到可写文件夹，双击「启动工作台.vbs」。工作台用 Microsoft Edge 独立窗口显示。 |
| macOS 15 或更高版本，Apple 芯片 | 解压，把「趋势判断工作台.app」拖到「应用程序」后双击。开发者已在 Mac mini M4 上实测打开 v1.3.0。 |

Mac 首次打开。 本版本采用临时签名，尚未经 Apple 公证。如首次打开时系统提示无法验证开发者，请先确认应用来自本项目的 GitHub 发行页，然后到「系统设置」→「隐私与安全性」，在「趋势判断工作台」的提示旁点「仍要打开」，按系统提示确认。详情见 Apple 的首次打开说明。

两个压缩包都包含运行环境。行情通过网络获取，工作台在本机运行，无需 GPT 账号或交易账户。

行情断开时，工作台会按当前网络尝试其他现货来源，保持交易对和报价币一致。电脑可直连，也可沿用 Windows 或 macOS 的系统手动 HTTP/HTTPS 代理。刷新失败时，已经打开的图会保留同一标的、同一周期上次取得的 K 线，并暂停新信号。网络恢复后可点「刷新行情」。
