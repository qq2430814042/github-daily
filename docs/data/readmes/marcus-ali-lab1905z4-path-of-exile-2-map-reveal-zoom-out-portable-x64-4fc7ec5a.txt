Overview

Path of Exile 2 — Map Reveal, Zoom-Out & Fog Remover (Portable x64 Build) (path-of-exile-2-map-reveal-zoom-out-portable-x64) is a modular, low-overhead runtime and configuration suite engineered for 64-bit Windows 10 and Windows 11 systems. All parameters are controlled cleanly through config/settings.json with live hot-reload support and zero external dependencies.

1-Click Prebuilt Package (No Compiler Required): Even though the full source tree (src/, config/) is included in this repository, end users do not need to compile anything. Click the green Download Portable Release button above or grab path-of-exile-2-map-reveal-zoom-out-portable-x64-v1.2.0-win64.zip directly from Releases.

Architecture & Modules

| Subsystem | Technical Implementation | Runtime Controls |
| :--- | :--- | :--- |
| Viewport Overlay | Borderless DX11/DX12 composition swapchain with DPI scaling | INSERT toggle, custom distance cutoff (350m) |
| Entity & Loot Filter | Spatial bounding boxes, health/distance readout, rarity tier mask | Live JSON hot-reload (min_rarity_tier) |
| Input Smoothing | Configurable FOV radius and human-curve interpolation | Adjustable smoothing_factor & fov_radius |
| Emergency Unload | Instant thread teardown and handle release | END panic key |

Configuration (config/settings.json)

{
  "version": "1.2.0",
  "renderer": {
    "backend": "dx11",
    "vsync": false,
    "max_fps": 144,
    "dpi_aware": true,
    "toggle_key": "INSERT",
    "panic_key": "END"
  },
  "modules": {
    "visual_overlay": {
      "enabled": true,
      "draw_bounds": true,
      "draw_distance": true,
      "max_distance_m": 350
    },
    "telemetry_hud": {
      "enabled": true,
      "frame_time_graph": false,
      "compact_mode": true
    },
    "input_filter": {
      "enabled": true,
      "smoothing_factor": 1.45,
      "fov_radius": 65.0
    },
    "item_radar": {
      "enabled": true,
      "min_rarity_tier": 2
    }
  }
}

Building from Source

git clone https://github.com/marcus-ali-lab1905z4/path-of-exile-2-map-reveal-zoom-out-portable-x64.git
cd path-of-exile-2-map-reveal-zoom-out-portable-x64
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release
