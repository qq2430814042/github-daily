Windows PDF Editor & Page Organizer is a free, open-source PDF editing application for Windows that makes managing PDF documents simple. Merge PDF files, split documents, rotate pages, crop margins, and rearrange page layouts using an intuitive visual interface — no command line or professional editing experience required.

⬇️ Installation

Download the Windows application

1. Open the repository's Releases page.
2. Download the latest release archive Windows PDF Editor & Page Organizer 4.0.4.zip.
3. Extract the archive into a folder of your choice.
4. Keep Windows PDF Editor & Page Organizer 4.0.4.exe and libvlc.dll together in that folder.
5. Double-click Windows PDF Editor & Page Organizer 4.0.4.exe to launch the application.

✨ Features

- 📚 Merge PDF Files — Combine multiple PDF documents into one organized file with control over page order.
- ✂️ Split PDF Documents — Separate large PDF files into smaller documents and extract the pages you need.
- 🖱️ Drag-and-Drop Page Reordering — Visually rearrange PDF pages to create the exact document structure you want.
- 🔄 Rotate PDF Pages — Correct portrait and landscape orientations without changing the rest of your document.
- 📐 Crop PDF Pages — Remove unwanted margins and adjust page boundaries for cleaner documents.
- 👁️ Visual PDF Preview — Inspect page thumbnails and document layouts before exporting your changes.
- 📂 Multiple Document Workflow — Work with pages from different PDF files in one convenient workspace.

🖼️ Overview

A Simpler Way to Manage PDF Documents

Forget complicated professional PDF editing suites when you only need to organize pages or combine documents.

The visual workspace makes common PDF operations accessible:

| Operation | What it does |
|---|---|
| Merge | Combine several PDF files |
| Split | Extract pages into separate PDFs |
| Reorder | Change the sequence of pages |
| Rotate | Correct page orientation |
| Crop | Adjust visible page boundaries |
| Preview | Review the document before saving |

Whether you are organizing scanned paperwork, preparing business documents, combining reports, or cleaning up study materials, the application provides practical PDF editing tools in one desktop workspace.

🚀 Usage

Getting started with PDF page management is straightforward:

1. Open PDF documents — Load one or more PDF files into the application.
2. Arrange your pages — Review the visual page thumbnails and move pages into the desired order.
3. Edit the layout — Rotate individual pages, crop margins, or remove unwanted sections from your document.
4. Merge or split — Combine documents or separate selected content into smaller PDF files.
5. Review your changes — Check the resulting page arrangement before exporting.
6. Save your PDF — Export the organized document for sharing, printing, or archiving.

Yes. The project is free and open source under the MIT License.

Yes. You can combine multiple PDF documents into a single file and organize their page order.

Yes. Page rotation allows you to correct incorrectly oriented pages.

Yes. You can adjust page boundaries to remove unwanted margins.
