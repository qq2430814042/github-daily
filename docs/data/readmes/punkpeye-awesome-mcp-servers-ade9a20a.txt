What is MCP?

MCP is an open protocol that enables AI models to securely interact with local and remote resources through standardized server implementations. This list focuses on production-ready and experimental MCP servers that extend AI capabilities through file access, database connections, API integrations, and other contextual services.

Confused about Local 🏠 vs Cloud ☁️?
* Use local when MCP server is talking to a locally installed software, e.g. taking control over Chrome browser.
* Use cloud when MCP server is talking to remote APIs, e.g. weather API.

🔗 Aggregators

Servers for accessing many apps and tools through a single MCP server.
- inth3shadows/terse  🐍 🏠 🍎 🪟 🐧 - Transparent proxy that sits in front of any other MCP server and shrinks its tool output before it reaches the model. Lossless by default — a denser encoding of the same bytes, with a round-trip gate asserting an exact inverse, so nothing is dropped or summarised. Repeated calls to the same tool emit a delta against the prior result instead of the whole payload. Per-tool opt-in, no decode step, no model in the loop. uv tool install terse-mcp then terse proxy --
