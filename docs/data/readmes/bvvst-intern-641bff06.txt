Intern

Intern is a fully rounded variant of Inter by Rasmus Andersson. It's a variable font with two axes, weight (100–900) and optical size (14–32).

@font-face {
  font-family: "Intern";

  font-weight: 100 900;
  font-style: normal;
  font-display: swap;
}

Coverage

Latin, including Vietnamese, plus digits, punctuation, currency and common math symbols. There
is no Greek, Cyrillic or italic yet.
