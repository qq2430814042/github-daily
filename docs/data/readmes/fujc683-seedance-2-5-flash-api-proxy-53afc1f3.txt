What "中转" means here

Calling a Chinese or overseas video model directly usually means: a foreign
credit card, an overseas phone number, an unstable direct connection, and one
key per vendor. A 中转 (relay) puts all of that behind one domestic endpoint.

| | Direct to vendor | Relay (APIMart) |
|---|---|---|
| Payment | foreign card required | Alipay / WeChat / card |
| Network | direct, often throttled | domestic-optimised relay |
| Keys | one per vendor | one key for all models |
| Model switch | rewrite code | change one string |
| Invoice | overseas | domestic invoice available |
| Failure handling | per-vendor | unified retry + fallback |

Endpoint

curl -X POST https://api.apimart.ai/v1/videos/generations \
  -H "Authorization: Bearer $APIMART_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"seedance-2-5-flash","prompt":"slow orbit around a ceramic mug","duration":4,"ratio":"16:9","resolution":"720p"}'

The relay is OpenAI-compatible in shape, so existing clients work by
changing base_url and model only.

Latency and reliability

- Video tasks are asynchronous — poll task_id, do not block a request
- A 4s 720p Seedance clip typically finishes in 40-90 seconds
- Failed tasks are refunded automatically
- The relay retries upstream 5xx internally before surfacing an error

Common questions

Do I need a VPN? No — the relay is reachable from mainland China directly.

Can I pay monthly? Yes, prepaid balance with per-second video billing.

Is it stable for production? Use a queue on your side; treat every task as
retryable, and store the MP4 immediately (URLs expire after 72h).
